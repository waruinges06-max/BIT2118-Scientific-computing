# BIT 2118 – Scientific Computing Group Work

This project follows the instructions in the supplied BIT 2118 assignment. It contains Tasks 2–20 (all listed tasks).

## Project structure
- `code/` – one Python program for each task.
- `results/` – generated graphs are saved here when the relevant program is run.
- `ASSIGNMENT_REPORT.md` – concepts, inputs, operations, parameter changes, output meanings, graph interpretations and related applications.
- `requirements.txt` – Python libraries needed.

## Setup in PyCharm
1. Install Python 3.10 or newer.
2. Open this folder in PyCharm.
3. Open the PyCharm terminal and run: `python -m pip install -r requirements.txt`
4. Open any file in `code/` and click Run.
5. For graph-based tasks, a graph window will appear and a PNG copy will be saved in `results/`.

## GitHub submission
The assignment says GitHub submission is individual. Create a new repository under your own GitHub account, for example `BIT2118-Scientific-Computing`, and upload this complete project. Do not submit a shared group repository. Copy your repository URL and submit it together with the documentation through VLMS.

## Important
The numerical values in the programs are illustrative inputs for the scenarios described in the assignment. Review the outputs produced on your own computer and include your own screenshots if your lecturer requires evidence of execution.
